# MKT · STP 战略脚手架

把任意产品/品牌描述 → Kotler 框架下的完整 STP 战略文档。

## 适用场景
- 求职：增长产品 / AI PM / 电商出海 / 数据产品 面试策略题
- 工作：新功能 launch 前的定位梳理
- 实战：竞品 / 品牌差异化诊断
- 设计：用户分层 / Persona 草案

## 输入
- **产品/品牌描述**（必填）：产品名、所属品类、当前定位、目标
- **场景信息**（选填）：目标客群线索、已知竞品、痛点、时间窗口

## 输出结构

### Part 1 · Segmentation 维度建议
判断应该用哪几个基础维度切：

| 维度 | 内容 |
|---|---|
| Demographic | age / life-cycle / gender / income |
| Geographic | regions；PRIZM = geo+demo |
| Behavioral | loyalty / occasions / usage rate |
| Psychographic | lifestyle / values / traits |
| B2B（如果是 B2B） | 行业规模 / operating / purchasing / situational / personal |

输出：
- **主推维度**：哪 2-3 个对该产品最关键
- **切分理由**：3 句话以内的方法论论证
- **示例细分群**：3-5 个示例性 segment label

### Part 2 · Targeting 策略
- **覆盖策略**：mass marketing / targeted marketing / mass customization（说明三者的规模×个性化取舍）
- **战略层**：Compatibility（我配不配）vs Attractiveness（它值不值）
- **战术层**：Effectiveness（多有效）vs Efficiency（多高效）
- **Persona 草案**：1-2 个 detailed profile（含 demographic + psychographic + behavioral + pain + gain）

### Part 3 · Positioning 陈述
使用 Kotler 标准模板：

> **Among (target segment), our brand is (point-of-difference) within (frame of reference), because (reason to believe).**

按价值主张三域展开：
- **Functional value**：功能价值（这个产品解决什么问题）
- **Psychological value**：心理价值（让用户感觉如何）
- **Monetary value**：货币价值（性价比逻辑）

### Part 4 · POD vs POP 拆分
- **POD**（Point-of-difference）：差异化属性
  - 判据：**D**esirable / **D**eliverable / **D**ifferentiating
- **POP**（Point-of-parity）：等同点
  - 形式：Category / Correlational / Competitive
- **口诀**：**POP 入局，POD 赢局**

### Part 5 · 可持续优势三策略
判断当前定位的护城河在哪一类：
- 现有属性差异化（differentiate on an existing attribute）
- 引入新属性（introduce a new attribute）
- 建设强势品牌（build a strong brand）

### Part 6 · 注意事项
主动提醒用户：
- **Frame of reference** 是否清晰（评估基准是什么）
- 是否需要 **Decoy effect**（不对称支配）
- **Straddle positioning** 适用场景（如 Lululemon：performance × fashion）

## 不做什么
- 不替代真正的市场数据采集
- 不替用户做最终决策（只产出策略草案）
- 不输出超长营销计划（专注 STP 战略层）

## 输出语言
默认中文。引用专业术语时保留英文（POD / POP / Frame of reference 等）。
